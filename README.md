# Semplicemente Siti – sito portfolio

Sito statico (HTML, CSS, JavaScript vanilla) pronto per GitHub Pages.

## Da personalizzare prima di pubblicare

Apri `index.html` e usa Trova e sostituisci (Ctrl/Cmd+F):

| Cerca            | Sostituisci con                                                  |
|------------------|------------------------------------------------------------------|
| `39NUMERO`       | il tuo numero con prefisso, es. `393331234567` (compare 3 volte) |
| `TUOUSERNAME`    | i tuoi username GitHub, LinkedIn e Instagram                     |
| `NOME COGNOME`   | i tuoi dati nel footer (titolare, P.IVA / C.F., email)           |

Nei link WhatsApp il testo dopo `?text=` è il messaggio già scritto per chi ti contatta: modificalo o cancellalo.

## Portfolio
Le tre card usano mockup SVG d'esempio in `assets/`. Sostituisci immagini, titoli e link "Vedi la demo" con i tuoi lavori reali.

## Pubblicazione su GitHub Pages
1. Crea un repository e carica tutti i file di questa cartella.
2. Vai in Settings → Pages, scegli il branch `main` e la cartella `/ (root)`.
3. Dopo qualche minuto il sito è online.
