# Semplicemente Siti – sito portfolio

Sito statico (HTML, CSS, JavaScript vanilla) pronto per GitHub Pages.

## File
- `index.html`, `style.css`, `script.js`: il sito
- `privacy.html`, `cookie.html`: Privacy Policy e Cookie Policy
- `assets/`: favicon e anteprime illustrative del portfolio
- Il sito non usa cookie, analytics né font esterni: se aggiungi Google Analytics, Google Fonts, mappe o video, aggiorna `cookie.html` e `privacy.html` e aggiungi un banner di consenso.
